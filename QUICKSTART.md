# ⚡ Quick Start - 5 Minutes

## For Beginners

### 1️⃣ Download & Install Node.js
- Go to https://nodejs.org/
- Click "LTS" button
- Install it
- Restart your computer

### 2️⃣ Open Terminal/Command Prompt

**Windows:**
- Press `Win + R`
- Type `cmd`
- Press Enter

**Mac:**
- Press `Cmd + Space`
- Type `terminal`
- Press Enter

**Linux:**
- Press `Ctrl + Alt + T`

### 3️⃣ Copy & Paste These Commands

```bash
git clone https://github.com/traviskeenpro-jpg/keen-mix-dj.git
cd keen-mix-dj
mkdir uploads
npm install
npm start
```

✅ Wait for installation to complete (2-3 minutes)

### 4️⃣ Open Browser

Go to: **`http://localhost:5173`**

### 5️⃣ Start Mixing!

- Click "🎧 Load" to upload music
- Click ▶️ to play
- Move sliders to control
- Click effects to customize
- Click "📹 Record" to save

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Space` | Play/Pause |
| `1` | Load Deck A |
| `2` | Load Deck B |
| `R` | Start Recording |
| `S` | Stop Recording |

---

## Common Issues

**Q: Nothing appears in browser?**
A: Wait 30 seconds for the app to load, then refresh (Ctrl+R)

**Q: "Port already in use"?**
A: Run: `npm run dev -- --port 3000`

**Q: Files won't upload?**
A: Make sure `uploads` folder exists: `mkdir uploads`
